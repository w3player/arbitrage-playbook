# 模型六：Earn 收益轮动

## 一句话结论

把资金从低净收益金库迁到高净收益金库，赚取持有期内的风险调整后 APY 差。它是组合 carry 优化，不是瞬时无风险套利；应优先研究同链、同资产、可随时退出的成熟金库。

## 1. 模型与 LI.FI 的作用

```text
链 A / Vault A / USDC
  -> 提取 -> 必要时兑换与跨链 -> 存入
链 B / Vault B / USDC
```

LI.FI Earn 用于发现收益机会、读取当前 APY/TVL/资产/链/协议、查询用户仓位；Composer 可组织兑换、跨链、合约调用、存入及受支持的提取流程。

边界：

- 展示 APY 不是未来锁定收益，数据与交易能力刷新存在时间差；
- Composer 可编排步骤，但跨链前后不是全局原子事务；
- 可展示不代表同时支持自动存入和提取；
- 底层协议、金库策略、资产和链的风险不会被聚合接口消除。

## 2. 三种实施方式

| 方式 | 示例与收益来源 | 主要风险 | 推荐 |
|---|---|---|---|
| 同链同资产轮动 | 同链将 USDC 从 Vault A 迁到 Vault B | APY 衰减、协议与退出风险；成本较易估算 | 首选 |
| 跨链同资产轮动 | 链 A USDC 金库迁到链 B USDC 金库 | 桥延迟、资产版本、目标链、部分完成及未来返程成本 | APY 差和持有期足够大时采用 |
| 份额/激励错价 | 奖励代币、积分、份额折价或短期补贴 | 领取、归属、流动性、价格与估值高度不确定 | 仅作额外上行 |

## 3. 推荐前提

| 维度 | 必须具备 |
|---|---|
| 可比性 | 本金相同或经济上等价；区分原生、桥接、封装和不同发行方；统一基础 APY、奖励、复利与费用口径；只比较相近风险等级 |
| 可持续性 | APY 差不是瞬时排名变化；知道收益来源；能监控 APY、TVL、利用率、奖励价格与容量 |
| 退出 | 核实 `isRedeemable` 或等价能力；了解锁定、冷却、队列、额度、暂停与底层流动性；预估回到基准资产的完整成本 |
| 资金 | 预期持有期显著长于盈亏平衡期；限制金库/协议/链/资产敞口；保留可立即使用的流动性；规模适合 gas 与容量 |
| 风险 | 审查协议、管理者、策略合约、预言机、借款人与管理员权限；新协议和高权限合约采用更大折扣与更小仓位 |
| 执行 | 交易前重新验证报价、存入/提取能力和链上状态；跨链阶段有目标链 gas 与失败恢复路径 |

## 4. 执行流程

1. 定义基准资产，例如原生 USDC，并建立允许的等价资产白名单。
2. 计算当前仓位的可退出价值、净 APY 和完整退出成本。
3. 从 Earn 获取候选，按资产、链、协议、TVL、能力和风险过滤。
4. 将 APY 拆成基础收益、奖励、手续费和补贴。
5. 估算提取、兑换、跨链、存入，以及未来退出的全路径成本。
6. 计算保守 APY 差、盈亏平衡天数和压力损失。
7. 只有风险调整后的改善超过阈值才执行。
8. 存入后核对实际份额、成本基础和可赎回状态。
9. 持续监控收益、TVL、利用率、奖励、协议状态与退出能力。

跨链版本应把“提取并到达目标链”和“目标链存入”作为两个状态阶段。前者完成、后者失败时，资金会停在目标链钱包或中间资产中。

## 5. 收益与盈亏平衡

设：

- `V`：迁移本金；
- `C_move`：进入新仓的全部成本；
- `C_exit`：未来退出的增量成本；
- `Δr`：新旧仓位的保守净年化收益率差。

```text
breakEvenDays = (C_move + C_exit) / (V × Δr) × 365

netPnl
= baseInterest
+ realizedRewardValue
+ vaultSharePriceChange
- withdraw/swap/bridge/deposit/futureExitCosts
- depegAndSlippageLoss
- protocolOrStrategyLoss
- capitalOpportunityCost
```

`Δr <= 0` 时没有迁移逻辑；持有期若只略长于盈亏平衡期，也没有足够缓冲。

保守估值：基础 APY 使用历史分位或衰减值；奖励按可领取概率、归属期和卖出冲击折价；未上市积分不计核心收益；退出成本用压力报价；未实现奖励不按页面价格全额入账。

## 6. 损失与控制

| 风险 | 如何亏损 | 关键控制 |
|---|---|---|
| APY 衰减 | 高收益吸引资金后下降，迁移完成时收益差已消失 | 最低改善阈值、保守 APY、持有期缓冲和轮动冷却期 |
| 奖励贬值 | 奖励价格下跌、流动性不足、归属或无法领取 | 基础/奖励分开计价；奖励折价；积分仅作上行 |
| 本金/份额减值 | 策略亏损、坏账、清算、预言机、再质押罚没或会计错误 | 把本金变化计入回撤；协议、金库和策略限额 |
| 合约/管理员 | 漏洞、升级、暂停、密钥或治理攻击 | 审查权限与审计；高权限/新协议小仓位；跨协议分散 |
| 无法提取 | 仅可存入、流动性不足、冷却、队列或协议暂停 | 入场前确认可赎回；限制锁定仓位；保留流动资产 |
| 跨链部分完成 | 提取后桥接退款，或桥成功而存入失败，旧收益仓已失去 | 分阶段状态机、实际到账核验、目标链 gas 和恢复路径 |
| 稳定币/包装脱锚 | 高 APY 可能只是更高信用风险补偿 | 地址级资产分类、脱锚阈值和发行方/桥版本限额 |
| TVL/容量错觉 | 高 TVL 不等于退出深度；低 TVL 会摊薄收益或放大集中度 | 同时检查容量、利用率、退出流动性和存入后的 APY |
| 借贷/预言机 | 抵押物跳跌、清算失败、坏账、预言机延迟或操纵 | 了解底层借款与抵押；压力测试坏账和预言机事件 |
| 数据陈旧 | 大额流入、奖励调整或暂停后，页面仍显示旧 APY/能力 | 执行前重查并持续采集；异常 APY/TVL 变化自动暂停 |
| 频繁轮动 | 重复 Gas、滑点、存取费与税务成本吞噬收益 | 冷却期、双向迁移成本和最小持有期 |
| 链/基础设施 | 拥堵、暂停、重组、RPC 或 Gas 阻止退出 | 链级限额、备用 RPC、应急 gas 与退出预案 |
| 幸存者偏差 | 只回测仍存活金库，遗漏攻击、关闭、减值和锁仓样本 | 保留退市/失败样本和事件时间线 |
| 费用/税务 | 管理、绩效、提前退出、领取和链上费用未进 APY；税务降低净收益 | 全费用口径；按适用地区单独评估会计与税务 |

组合层面还应限制协议、金库、链、稳定币和策略管理者的集中度；TVL 急降、利用率过高、奖励暴跌或协议暂停时停止新增或退出。

## 7. 回测

不能用今天的 Earn 排名推断历史表现。需定期保存：

- 总/基础/奖励 APY、TVL、容量、利用率和存取能力；
- 底层资产与份额价格、奖励价格/流动性/领取/归属；
- 进入、退出、兑换和跨链报价；
- 协议暂停、攻击、减值、队列和退市事件；
- 实际份额、成本基础和可赎回价值。

回放必须模拟数据与执行延迟、资金进入后的 APY 衰减、最短持有和冷却期、双向成本、奖励折价/卖出冲击、提款队列、跨链异常，以及已消失金库。

报告净年化与 IRR、最大回撤、本金损失、基础/奖励/资产价格的收益贡献、换手与迁移成本占毛利比例、资金不可用时间、APY 下降后的水下时间、各风险敞口，并与“不轮动”基准比较。

## 8. Go / No-Go

### Go

- [ ] 本金资产和收益口径可比。
- [ ] 风险折价后的 APY 差仍显著为正。
- [ ] 预期持有期远长于保守盈亏平衡期。
- [ ] 存入、提取和退出流动性均已确认。
- [ ] 进入、未来退出和跨链全成本已计入。
- [ ] 协议、金库、链和资产均在限额内。
- [ ] 奖励大幅贬值后，基础收益逻辑仍可接受。

### No-Go

- 利润主要依赖不可估值积分或短期奖励；
- 不知道收益来源，只看到展示 APY；
- 不可赎回、队列不透明或退出深度不足；
- 迁移后短期需要用钱；
- APY 差不足以覆盖双向成本；
- 更高收益来自不可接受的信用或协议风险；
- 回测只保留当前存活金库。
