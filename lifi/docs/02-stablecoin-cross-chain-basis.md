# 模型二：稳定币跨链价差套利

## 一句话结论

利用同一稳定币的链间价差、原生/桥接版本基差或不同稳定币的短期偏离。方向波动通常小于 WETH 库存，但风险并未消失，而是转为发行信用、脱锚、冻结、桥包装与赎回风险。

## 1. 模型与 LI.FI 的作用

策略在多链预置 USDC、USDT、DAI、USDC.e 等库存，捕获：

- 同一稳定币在不同链的价格差；
- 原生与桥接版本的折溢价；
- 不同稳定币的短期偏离；
- 桥接流动性和赎回摩擦形成的基差。

LI.FI 提供同链/跨链 Quote、bridge/exchange 筛选、费用、Gas、最低输出、中间资产和跨链状态。但 Token 标准化不能替代尽调；同名资产仍须按链 ID + 合约地址区分。

## 2. 推荐前提

| 维度 | 必须具备 |
|---|---|
| 资产 | 明确发行方、抵押、赎回主体与资格；区分原生、官方跨链和第三方包装；记录冻结、暂停、升级与治理权限；建立地址白名单和风险等级 |
| 市场 | 至少两处独立退出流动性；多金额档位仍覆盖全成本；实时监控脱锚、池深、桥状态与发行方公告 |
| 资金 | 对稳定币、发行方、桥版本和链分别设 NAV 上限；保留不相关的应急结算资产 |
| 系统 | `PARTIAL` 时识别实际中间 Token；按真实可卖价而非固定 1 美元估值；设置停止新增、只减仓和紧急退出阈值 |

## 3. 三种子模型

| 类型 | 示例 | 风险重点 |
|---|---|---|
| 同资产链间价差 | 链 A 买原生 USDC，链 B 卖原生 USDC | 信用结构较一致，主要是流动性、单腿与再平衡 |
| 原生/桥接版本基差 | `USDC ↔ USDC.e`、`USDT ↔ 桥包装 USDT` | 价差可能是桥信用溢价，不保证均值回归 |
| 不同稳定币基差 | `USDC ↔ USDT/DAI/USDe` | 需分别建模中心化储备、超额抵押、合成或收益型资产风险 |

## 4. 执行流程

1. 按精确地址采集各链稳定币双向 Quote。
2. 计算真实可成交价、`toAmountMin` 和多金额深度。
3. 检查发行方、桥、赎回与当前脱锚原因。
4. 扣除 Gas、交易、再平衡、赎回和脱锚准备金。
5. 在两链尽量同时成交相同 Token 数量。
6. 按实际到账链、地址和数量更新库存。
7. 等待反向机会；触及库存阈值时再平衡。

无法直接赎回的桥接版本必须按二级市场保守退出价估值，并追加流动性折扣。

## 6. 损失与控制

| 风险 | 如何亏损 | 关键控制 |
|---|---|---|
| 脱锚扩大 | 0.99 买入后跌至 0.90，损失远大于预期 1% 基差 | 分级阈值：停止新增、只减仓、紧急退出；压力测试极端价格 |
| 永久信用事件 | 储备、托管银行、抵押品、治理或赎回暂停使锚定永久破坏 | 按发行方合并敞口；不用“必然回归”作为入场依据 |
| 桥版本信用 | 包装资产不可直接向发行方赎回，依赖桥储备、迁移合约和特定链 | 原生/包装分开估值与限额；准备无桥退出路径 |
| 冻结/黑名单 | 余额存在但无法转移、卖出、赎回或桥接 | 审查权限；限制中心化发行方敞口；异常时停止新增 |
| 流动性枯竭 | 脱锚时 LP 撤出、桥停用、DEX 深度骤降 | 使用危机深度而非正常平均滑点；保留第二退出场所 |
| 单腿失败 | 买入问题资产后卖出失败，或卖出后价格反弹导致补回变贵 | 使用公共单腿限额、补腿与停机机制 |
| 赎回摩擦 | KYC、最低额、银行工作日、地域、费用或暂停使理论净值不可实现 | 只有真实拥有赎回资格才按赎回净值估值 |
| 跨链中间资产 | `PARTIAL` 后收到 USDC.e、axlUSDC 等，信用和可用性改变 | 核对真实地址并隔离，禁止自动并入可用库存；参见 [Intermediate Tokens](https://docs.li.fi/guides/intermediate-tokens) |
| 固定成本 | 正常基差小，approve、两边交易、桥接与恢复成本吞噬利润 | 用 P95 全成本和多金额容量曲线准入 |
| 合约/链 | 稳定币、DEX、桥、LI.FI、目标链和治理形成复合攻击面 | 链、协议、桥与发行方限额；单点失效仍有退出路径 |

## 7. 回测

采集各链逐时/逐区块价格与池深、多金额滑点、历史脱锚幅度/恢复时间、原生与桥接兑换路径、真实赎回时间/费用、LI.FI Quote/Gas/工具/状态，以及危机期间“无路线”和流动性消失样本。

至少压力测试：`0.995`、`0.98`、`0.90`、`0.50` 和完全不可交易。这些是损失情景，不表示价格必然恢复。

## 8. Go / No-Go

### Go

- [ ] 每个 Token 的信用与桥接版本已分类。
- [ ] 策略真实拥有假设中的赎回通道。
- [ ] 严重脱锚损失不超过风险预算。
- [ ] 单桥/单池失效后仍有退出路径。
- [ ] 净收益覆盖 P95 成本和脱锚准备金。
- [ ] 中间 Token 可按真实地址识别和隔离。

### No-Go

- 只凭 symbol 判断资产等价；
- 把稳定币当成无信用风险现金；
- 假设所有折价都会均值回归；
- 依赖自己无权使用的发行方赎回；
- 没有脱锚停机机制和资产白名单。
