# 模型五：跨链循环套利

## 一句话结论

从链 A 的 `X` 出发，经链 B 再回到链 A 的 `X`，赚取闭环净增量。逻辑直观，但跨链不原子，返程报价无法提前锁定；纯串行版本更适合研究，规模化实盘通常需要预置库存。

## 1. 模型与 LI.FI 的作用

```text
链 A: X
  -> 兑换/跨链
链 B: Y
  -> 兑换/跨链
链 A: X'
```

只有 `X' - X` 覆盖所有显式成本、失败准备金和资本占用后，才有经济利润。

LI.FI 可提供双向 Quote/Route、多个桥与 DEX 候选、`transactionRequest`、`toAmount`、`toAmountMin`、Gas/fee，以及 `COMPLETED/PARTIAL/REFUNDED/FAILED` 状态。它不能让完整循环原子化：第一段完成时，第二段面对的是新的区块、价格和流动性。

与[多链预置库存](./01-prefunded-cross-chain-inventory.md)相比，本模型把桥接放进交易闭环，因此更依赖路径、时间和返程报价；预置库存模型则把桥接推迟到事后，代价是长期库存占用。

## 2. 两种实施方式

| 方式 | 做法 | 优点 | 代价 |
|---|---|---|---|
| 串行闭环 | 等 A→B 实际到账，再以真实数量执行 B→A | 账务清晰，无需长期目标链库存 | 返程无法锁价；机会衰减；桥接与退款占款；中途失败留下 Y |
| 预置库存加速 | 链 B 用预置 Y 立即执行返程，A→B 到账后补回库存 | 两段更接近同时成交，减少桥延迟暴露 | 引入多链库存、缺口、再平衡和链级限额 |

纯串行更适合研究报价效率；稳定实盘通常只能采用第二种，并纳入模型一的库存风控。

## 3. 推荐前提

| 维度 | 必须具备 |
|---|---|
| 市场 | 价差具有持续性；正反路径存在独立定价/流动性；目标金额扣除价格影响后仍盈利；至少有两条替代桥/退出路径 |
| 资产 | 按链与地址识别原生、包装和桥凭证；中间资产可可靠估值、交易和恢复 |
| 资金 | 可承受桥接/退款占款；设置链级库存和损失预算；目标链有 gas；预置版本有单腿与连续同向机会缓冲；计入真实资本时间成本 |
| 系统 | 报价、签名、广播、状态跟踪自动化；以真实到账触发下一段；处理 `PARTIAL/REFUNDED/超时`；支持重组、RPC、nonce 和 gas 异常 |
| 安全 | Token、桥、DEX、Router 与中间资产白名单；保存报价、成交、耗时、到账差异和失败原因 |

## 4. 执行流程

1. 确定起始资产 `X`、链 A、链 B 和中间资产 `Y`。
2. 查询 A→B 路径，记录预期/最低到账、成本与耗时。
3. 用第一段的保守到账量查询 B→A。
4. 合并两段 Gas、协议/桥费、滑点、失败准备金和资金成本。
5. 保守利润超过阈值后才执行第一段。
6. 核对链 B 的真实资产和到账量，并重新获取返程报价。
7. 新报价仍符合退出条件才执行；否则按预案止损、等待、换路由或保留链 B 库存。
8. 回到链 A 后，以真实 `X'` 结算完整循环。

预置版本可提前执行返程腿，但跨链补库必须作为未完成头寸持续跟踪。

## 5. 盈亏

```text
grossPnl = finalX - initialX

netPnl
= grossPnl
- twoLegGas
- bridgeAndProtocolFees
- slippageAndPriceImpact
- hedgeCost
- capitalTimeCost
- failureAndRecoveryCost

conservativeFinalX
= 第二段基于第一段保守到账量计算的 toAmountMin
```

不能把同一时刻的两个最佳报价直接相乘：第二个报价在第一段到账时通常已过期。

## 6. 损失与控制

| 风险 | 如何亏损 | 关键控制 |
|---|---|---|
| 桥接期间反转 | 到达链 B 时返程收益消失；延迟与波动放大尾部损失 | 串行版本采用高安全边际；限制标的波动和最大完成时间 |
| 第二段失效 | 路由因流动性、Gas、区块或第三方报价变化不可用 | 到账后强制重报；准备替代退出；禁止盲发预构造交易 |
| `PARTIAL`/单腿成功 | 桥成功但目标 swap 失败，收到中间资产 | 按实际 Token 入账；白名单与专用恢复剧本 |
| 退款/长时间占款 | 退款链、金额和时间可能变化，并损失机会成本 | 保持在途状态；设置 P95/P99 占款预算和超时处置 |
| 费用复合 | 每段增加桥费、DEX 费、Gas 与滑点；小额受固定费影响，大额受冲击 | 多金额容量曲线；以 `toAmountMin` 和 P95 成本准入 |
| 中间资产 | 包装资产、桥凭证或小众稳定币脱锚、冻结、难赎回 | 地址级白名单和估值折扣；限制最大中间持仓 |
| 路径依赖/枯竭 | 第一腿改变目标池；其他套利者先消耗返程深度 | 顺序仿真；优先独立流动性；预置库存减少延迟 |
| MEV | 同链兑换被抢跑、夹击或复制，薄利被抽取 | 私有提交、严格滑点与最低利润 |
| 链/桥/协议 | 链暂停、最终性、RPC、验证器或合约异常；多套设施叠加 | 链/桥/协议限额、替代路径与自动暂停 |
| 目标链无 gas | 资产已到账但无法发返程交易 | 预置并监控各链 gas，保留应急补充 |
| 年化高估 | 忽略桥接和退款时间，按成交次数夸大周转率 | 按实际资金占用时长计算资本收益率 |
| 回测前视 | 用同一时刻两段报价，或用当前路由回放历史 | 按真实/采样延迟推进时间，并保留历史路线与失败样本 |

连续失败、桥耗时异常或机会衰减加快时自动暂停。预置版本还需设置库存偏离和低频净额再平衡。

## 7. 回测

LI.FI 提供当前报价与执行，不是完整历史报价库；需要自行采集：

- 请求/响应时间、route/tool/token/chain/amount；
- `toAmount`、`toAmountMin`、Gas、fee、报价有效期；
- 广播、源链确认、目标链到账时间；
- 实际到账地址/数量、状态与失败原因；
- 到账时重新查询的返程报价和最终 `X'`。

正确回放必须推进时间：

```text
t0：第一段报价与成交
t1 = t0 + 模拟桥耗时：使用当时的第二段报价
t2：计入第二段成交/失败和最终确认
```

报告：

- 报价毛利与实现净利差、机会半衰期；
- 桥耗时 P50/P95/P99、返程仍盈利概率和各状态比例；
- 最大亏损、资本占用与真实年化、容量曲线；
- 桥、链和中间资产的风险贡献。

压力测试覆盖价格跳变、Gas 激增、延迟扩大、目标链暂停、深度减半和中间资产脱锚。

## 8. Go / No-Go

### Go

- [ ] 压力场景的最低到账仍覆盖全成本。
- [ ] 机会寿命明显长于端到端执行时间。
- [ ] 有第二退出路径和中间资产处置方案。
- [ ] 可承受 P95/P99 桥接占款。
- [ ] 状态跟踪、恢复和对账已自动化。
- [ ] 单次失败不突破链级或组合预算。

### No-Go

- 利润依赖两个同时看到但无法锁定的报价；
- 只有乐观 `toAmount` 下盈利；
- 返程无替代流动性，中间资产无法估值/退出；
- 没有目标链 gas 或异常恢复；
- 一次 `PARTIAL`/退款损失即可吞掉长期利润；
- 回测未模拟桥接延迟和机会衰减。
